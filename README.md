# Coran Al Nour — version web

Paquet préparé pour une publication statique sur GitHub Pages.

## Contenu

- index.html : version V39 corrigée et auditée.
- Rapports d’audit : contrôles techniques, sourates, traduction et comparaison textuelle.

## Données et attribution

Le texte arabe et les traductions des versets sont chargés en ligne depuis Quran Foundation. La traduction des versets est la ressource française 31, attribuée à Muhammad Hamidullah. Les gloses mot à mot sont des propositions de travail et ne constituent pas une traduction certifiée.

## État de vérification

Les 6 236 versets et leurs références de traduction ont été vérifiés structurellement; les tests automatisés passent. La comparaison intégrale du texte coranique avec une édition indépendante reste inachevée. Le rapport signale notamment l’écart d’échantillon en 2:1. Aucune différence de texte coranique n’a été corrigée automatiquement.

Pour activer GitHub Pages après publication, sélectionner la branche main et le dossier / (root) dans les paramètres Pages du dépôt.
